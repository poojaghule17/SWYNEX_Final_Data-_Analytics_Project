# SWYNEX Task 4 - Data Analytics Project

## Project Overview
This project focuses on analyzing sales data to identify sales trends, profitable products, and regional performance.

## Objectives
- Clean and prepare the dataset
- Analyze sales and profit
- Identify top-performing products
- Analyze regional performance
- Create meaningful data visualizations
- Generate business insights

## Dataset
The dataset contains sales-related information such as:
- Order ID
- Order Date
- Customer Name
- Product
- Category
- Region
- Quantity
- Unit Price
- Sales
- Profit

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel
- SQL
- Power BI

## Project Steps
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. SQL Analysis
6. Power BI Dashboard
7. Business Insights

## Key Insights
The analysis will help identify sales trends, profitable products, high-performing regions, and areas for business improvement.

## Conclusion
This project demonstrates the use of data analytics techniques to transform raw sales data into meaningful business insights.
